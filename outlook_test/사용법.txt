쟈비스로 보내기 (Outlook 추가 기능) 사용법
==========================================
메일(본문·첨부·본문 그림)을 내 PC의 SLB 도우미를 거쳐 쟈비스 "받은 메일"로 보냅니다. 메일은 이 PC 밖으로 나가지 않습니다.

[처음 한 번]
1. PC 도우미를 새 버전(v1.4)으로: SLB_쟈비스 폴더의 slb_claude_bridge.py 가 이미 바뀌어 있습니다.
   켜져 있던 도우미 창을 닫고 "SLB도우미_실행"을 다시 실행하세요. 창 맨 위에 v1.4 가 보이면 됩니다.
2. GitHub(SLB_AI 저장소)의 outlook_test 폴더에 taskpane.html, manifest.xml 두 파일을 새 파일로 덮어 올립니다.
3. Outlook에 다시 등록: 브라우저에서 https://aka.ms/olksideload → 내 추가 기능 → 사용자 지정 추가 기능에서
   예전 "SLB 연결 테스트"를 제거 → "사용자 지정 추가 기능 추가 → 파일에서 추가" → manifest.xml 선택
   → Outlook을 껐다 켭니다. 리본에 "쟈비스로 보내기"가 생깁니다.
4. 메일을 선택하고 "쟈비스로 보내기"를 누른 뒤, 창 맨 위 "연결 키" 칸에 도우미 창에 나온 연결 키를 붙여넣습니다(한 번만).

[쓰는 법]
- 메일 한 통: 메일 선택 → "이 메일만 바로 보내기"
- 여러 통: 창 오른쪽 위 핀(고정)을 누른 뒤, 메일을 하나씩 선택하며 "담기" → 다 담았으면 "담은 메일 보내기"
  (쟈비스에게 한마디 칸에 "노무 자문으로 정리" 같은 메모를 남기면 쟈비스 받은 메일에 함께 보입니다)
- 쟈비스: 왼쪽 메뉴 "받은 메일" → 새 업무로 접수 / 진행 중 카드에 추가 / 노무 자문으로 정리 / 사례로 저장

[알아 둘 점]
- 도우미가 꺼져 있으면 보낼 수 없습니다. 그때는 "내용 복사" 후 쟈비스에 붙여넣으세요.
- 뉴스레터처럼 인터넷에서 불러오는 그림은 메일에 붙은 그림이 아니라서 보낼 수 없습니다.
- 첨부 한 개 15MB 넘는 파일, 메일 안에 첨부된 다른 메일(.msg)은 빼고 보냅니다(창에 표시).
- 4KB 미만의 작은 본문 그림(서명 아이콘 등)은 뺍니다. 본문 그림을 아예 빼려면 "본문에 붙은 그림도 보내기" 체크를 끄세요.
