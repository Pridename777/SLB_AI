쟈비스로 보내기 (Outlook 추가 기능) v1.5 사용법
==============================================
메일(본문·첨부·본문 그림)을 내 PC의 SLB 도우미를 거쳐 쟈비스 "받은 메일"로 보냅니다. 메일은 이 PC 밖으로 나가지 않습니다.

v1.5에서 바뀐 것
  - 리본에 버튼이 2개가 됩니다: [바로 보내기] [쟈비스로 보내기]
  - [바로 보내기]: 창을 열지 않고 선택한 메일 한 통을 바로 보냅니다. 메일을 바꿔도 버튼은 늘 그 자리에 있습니다.
  - [쟈비스로 보내기] 창: 메일을 Ctrl/Shift로 여러 통 고른 뒤 "선택한 메일 모두 담기"(또는 "모두 바로 보내기")를 누를 수 있습니다.

[처음 한 번] (GitHub에 올리고 Outlook에 다시 등록)
1. GitHub(SLB_AI 저장소)의 outlook_test 폴더에 아래 3개 파일을 올립니다. (taskpane.html, manifest.xml 은 덮어쓰기, commands.html 은 새 파일)
     manifest.xml / taskpane.html / commands.html
2. Outlook에서 예전 "쟈비스로 보내기"를 제거합니다.
   브라우저에서 https://aka.ms/olksideload → 내 추가 기능 → 사용자 지정 추가 기능에서 "쟈비스로 보내기" 제거
   → "사용자 지정 추가 기능 추가 → 파일에서 추가" → 새 manifest.xml 선택 → Outlook을 껐다 켭니다.
3. 메일을 선택하고 [쟈비스로 보내기]를 눌러 창을 엽니다. 연결 키는 이전에 넣은 것이 그대로 남아 있을 수 있습니다.
   (남아 있지 않으면 창 맨 위 "연결 키" 칸에 도우미 창의 연결 키를 한 번 붙여넣습니다.)
4. 다시 메일 한 통을 선택하고 [바로 보내기]를 눌러 봅니다. 메일 위쪽에 "쟈비스로 보냈습니다."가 뜨면 됩니다.

[쓰는 법]
- 메일 한 통을 빠르게: 메일 클릭 → [바로 보내기] (창 없이 끝)
- 여러 통을 한꺼번에: Ctrl 또는 Shift로 여러 통 선택 → [쟈비스로 보내기] → 창의 "선택한 메일 모두 담기"(한 번에 30통까지)
  * Windows의 Outlook은 메일을 바꾸면 창이 닫힙니다. 창 오른쪽 위의 핀(고정)을 누르면 메일을 바꿔도 열려 있습니다.
- 한마디 메모를 붙이고 싶을 때: 창에서 "담기"(또는 "모두 담기") 후 "쟈비스에게 한마디"에 적고 "담은 메일 보내기"
- 쟈비스: 왼쪽 메뉴 "받은 메일" → 새 업무로 접수 / 진행 중 카드에 추가 / 노무 자문으로 정리 / 사례로 저장

[알아 둘 점]
- 도우미가 꺼져 있으면 보낼 수 없습니다. [바로 보내기]는 메일 위쪽 빨간 줄로, 창은 창 안에 이유를 알려 줍니다.
- [바로 보내기]는 메일이 여러 통 선택되어 있으면 보내지 않고 안내만 합니다. 여러 통은 창에서 보내세요.
- [바로 보내기]가 "연결 키가 아직 없습니다"라고 하면 [쟈비스로 보내기] 창을 한 번 열어 주세요.
- 여러 통 선택은 Outlook이 새 버전이어야 합니다. 지원하지 않으면 창에 "선택한 메일 여러 통" 상자가 나타나지 않고, 한 통씩 담으면 됩니다.
- 뉴스레터처럼 인터넷에서 불러오는 그림은 메일에 붙은 그림이 아니라서 보낼 수 없습니다.
- 첨부 한 개 15MB 넘는 파일, 메일 안에 첨부된 다른 메일(.msg)은 빼고 보냅니다(창에 표시).
- 4KB 미만의 작은 본문 그림(서명 아이콘 등)은 뺍니다. [바로 보내기]는 항상 이 기준을 씁니다.
