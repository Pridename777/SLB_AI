SLB 연결 테스트 (Outlook 추가 기능) 사용법
=========================================
* 이 폴더는 기존 프로그램과 완전히 별개입니다. 기존 프로그램은 고치지 않았습니다.
* 목적: Outlook 클래식에서 "메일을 읽어 오는 버튼"이 되는지만 확인합니다. 메일 내용은 화면에만 표시하고 어디로도 보내지 않습니다.

1단계. 올릴 곳 정하기 (HTTPS 주소가 필요합니다)
  - 기존에 쓰던 GitHub 저장소(모바일 페이지)에 폴더 하나(outlook_test)를 통째로 올립니다.
  - 올린 뒤 주소가 https://pridename777.github.io/SLB_AI/outlook_test/taskpane.html 로 열리는지 브라우저로 확인합니다.
  - 열리면 manifest.xml 의 주소는 이미 https://pridename777.github.io/SLB_AI/outlook_test 로 맞춰 두었습니다. (주소가 다르면 메모장 "바꾸기"로 모두 고칩니다)

2단계. Outlook(클래식)에 등록하기
  - 메일 하나를 더블클릭해 따로 열거나, 받은 편지함에서 선택합니다.
  - 홈 → 오른쪽 "모든 앱" (또는 추가 기능 가져오기) → 내 추가 기능 → 하단 "사용자 지정 추가 기능" → 사용자 지정 추가 기능 추가 → 파일에서 추가 → manifest.xml 선택
  - "사용자 지정 추가 기능 추가" 항목이 없거나 막혀 있으면 회사가 막은 것입니다. 그 화면을 캡처해 알려 주세요.

3단계. 확인하기
  - 메일을 선택하고 리본의 "SLB 인사팀 → SLB 연결 테스트"를 누릅니다.
  - 오른쪽 창에 제목·보낸 사람·날짜·첨부·본문이 보이면 성공입니다.
  - "메일 내용 복사" → 메모장에 붙여넣기로 넘기는 방법을 확인합니다.
  - "내 PC 도우미 응답 확인"은 도우미(slb_claude_bridge.py)를 켠 상태에서 눌러 보세요. 401 또는 403이 나오면 정상(연결됨)입니다.

지우는 방법: 모든 앱 → 내 추가 기능 → 사용자 지정 추가 기능에서 "SLB 연결 테스트" 제거.
